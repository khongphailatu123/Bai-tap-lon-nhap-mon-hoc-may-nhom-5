## Cấu trúc Repository
* `main.py`: Mã nguồn chính thực thi tiền xử lý, huấn luyện 4 mô hình (K-NN, Naive Bayes, Decision Tree, Random Forest) và xuất biểu đồ.
* `WA_Fn-UseC_-HR-Employee-Attrition.csv`: Bộ dữ liệu IBM HR Analytics.
* Các file ảnh (`01_confusion_matrix.png`, `02_decision_tree.png`, `03_feature_importance.png`, v.v.): Các sơ đồ trực quan phục vụ báo cáo LaTeX.

## Hướng dẫn chạy chương trình
1. Cài đặt thư viện: `pip install pandas scikit-learn matplotlib seaborn`
